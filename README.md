# 🎮 Tic-Tac-Toe (Tick Cross Game)

A simple **console-based Tic-Tac-Toe** game written in **C++** for **Windows**.  
Two players take turns marking `X` and `O` on a **3x3 grid**. The first player to align three marks horizontally, vertically, or diagonally wins the game.  

---

## ✨ Features
- 👥 **Two-player mode** (Player 1: `X`, Player 2: `O`)
- ✅ **Input validation** to prevent invalid moves
- 🎨 **Colorful console output** (Windows only)
- 🏆 Declares the **winner** or **draw**

---
